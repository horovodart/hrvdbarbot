# Бар HOROVOD HUB → Telegram Mini App

Задача: перенести прототип `hub-bar-prototype.html` (склад напитков скушобни) в Telegram Mini App, которым пользуется вся команда.

## Файлы
- `hub-bar-prototype.html` — рабочий прототип: интерфейс, расчёты, тексты. Это эталон вида и логики, сохранить 1:1.
- `hub-bar-data.json` — текущие данные: `products` (14 позиций), `counts` (стартовый подсчёт 20.09.2026), `purchases` (пусто).

## Архитектура (всё бесплатно)
1. **Фронтенд** — статическая страница на GitHub Pages (репозиторий `horovod-hub-bar`). Подключить `https://telegram.org/js/telegram-web-app.js`, взять цвета темы из `Telegram.WebApp.themeParams`, вызвать `ready()` и `expand()`, использовать `HapticFeedback` на плюсах и минусах.
2. **Хранилище** — Google Таблица на horovod.art@gmail.com с листами `products`, `counts`, `purchases`. `stock` и `items` хранить как JSON в ячейке.
3. **API** — Google Apps Script Web App (`doGet`/`doPost`): list, addPurchase, addCount, addProduct, updateProduct, delete. Развернуть через `clasp`.
4. **Доступ** — каждый запрос несёт `Telegram.WebApp.initData`. Скрипт проверяет HMAC-SHA256 токеном бота из Script Properties и пускает только Telegram user id из белого списка (лист `team`). Токен никогда не попадает во фронтенд и в git.
5. **Бот** — через BotFather ставится кнопка меню (Menu Button) со ссылкой на GitHub Pages. Бот закрепляется в чате команды.
6. **Замена db** — все вызовы `claude.use("db")` в прототипе заменить на fetch к API. Коллекции остаются те же, поля те же.

## Логика (уже в прототипе, не менять)
- Подсчёт раз в 2 недели: холодильник и полки вместе, в тот же день касса и карта (сообщение платежа «napoj HUB»).
- Выпито = прошлый подсчёт + закупки − текущий подсчёт. Ожидаемые деньги = выпито платных × 1,50 €.
- Расчётный остаток между подсчётами = последний подсчёт + закупки − расход/день × прошедшие дни.
- Красный: запаса меньше чем на 14 дней. Жёлтый: меньше чем на 21 день. Пока подсчёт один, статус считается по полю `min`.
- «Что купить» считается на 28 дней и округляется до `pack`.
- Категории: `sale` (1,50 €), `free` (вода, бесплатно, но считается), `shared` (не продаётся).
